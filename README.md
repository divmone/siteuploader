# Site Uploader

Файловый менеджер для Windows, Linux и macOS. Программа открывает интерфейс в системном браузере, а локальный сервер Go слушает только `127.0.0.1`. Для работы нужен браузер и доступ к SFTP-серверу.

| Система | Файл в `dist` |
| --- | --- |
| Windows x64 | `SiteUploader.exe` |
| Linux x64 / ARM64 | `SiteUploader-linux-x64` / `SiteUploader-linux-arm64` |
| macOS Apple Silicon / Intel | `SiteUploader-macos-arm64` / `SiteUploader-macos-x64` |

В Windows откройте `.exe`. В Linux и macOS при необходимости выдайте файлу право на запуск через `chmod +x`, затем запустите его из терминала. Например, на Mac с Apple Silicon:

```sh
chmod +x ./SiteUploader-macos-arm64
./SiteUploader-macos-arm64
```

Сборки macOS без подписи разработчика и нотариального подтверждения Apple. Кнопка **Завершить работу** в боковой панели закрывает подключение и останавливает приложение. Параметр `-manual` выводит локальный адрес для ручного открытия в браузере.

## Подключение

1. Введите IP или имя сервера, порт SSH (обычно `22`) и имя пользователя.
2. Введите пароль SSH или укажите путь к закрытому SSH-ключу OpenSSH. Если ключ зашифрован, введите его пароль в поле пароля.
3. Введите путь к нужной папке, например `/var/www/site`. Пустое поле открывает домашнюю папку пользователя.
4. Нажмите **Подключиться**. При первом подключении сверьте отпечаток SHA256 с администратором сервера. Приложение запомнит подтверждённый ключ и отклонит соединение, если он изменится.

На сервере должна быть включена подсистема SFTP. Для загрузки, замены, переноса и удаления нужны соответствующие права на папку.

## Профили сайтов

Нажмите **+** рядом с заголовком **Сайты**, заполните поля и нажмите **Сохранить профиль…**. Чтобы вернуться к сайту, выберите его на боковой панели. Для обновления или переименования выберите профиль и сохраните его снова.

Если нужно запомнить пароль SSH или пароль ключа, введите его, поставьте флажок **Запомнить пароль при сохранении профиля** и сохраните профиль. Для защиты паролей используются DPAPI в Windows, Keychain в macOS и Secret Service в Linux. На Linux сохранение паролей требует запущенного хранилища Secret Service, например GNOME Keyring. Чтобы удалить сохранённый пароль, снимите флажок и снова сохраните профиль.

Настройки хранятся в подкаталоге `Site Uploader` системного каталога конфигурации. В Windows используется прежний `%APPDATA%\Site Uploader\settings.json`, поэтому сохранённые там профили и пароли открываются автоматически под той же учётной записью.

## Файлы

- Двойной щелчок открывает папку или редактор небольшого текстового файла UTF-8 (до 1 МБ).
- **Загрузить** выбирает один или несколько файлов. Их также можно перетащить из файлового менеджера в список.
- **Скачать** сохраняет выбранный файл на компьютер. Для замены на сервере загрузите новую копию и подтвердите замену.
- **Переименовать / переместить** (`F2`) принимает новое имя или путь, включая имя объекта, например `/var/www/archive/index.html`.
- **Папка** создаёт подпапку. **Удалить** (`Delete`) запрашивает подтверждение и удаляет файл, ссылку или пустую папку. `F5` обновляет список, когда фокус в файловом интерфейсе.

Для замены существующего файла и сохранения из редактора сервер должен поддерживать расширение SFTP `posix-rename@openssh.com`. Оно позволяет сохранить исходный файл до окончания передачи новой версии.

## Сборка

На Windows с Go выполните команды из папки проекта. Скрипт собирает все варианты в `dist`.

```powershell
go test ./...
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

На Linux и macOS командой `CGO_ENABLED=0 go build -o SiteUploader .` можно собрать приложение для текущей системы. Интерфейс HTML, CSS и JavaScript встроен в исполняемый файл. Для SFTP используется [pkg/sftp](https://github.com/pkg/sftp).
